Enable copying, text selection, and right-click menus on restricted webpages.

Enable Copy and Right Click is a lightweight, open-source extension that restores normal copy, text selection, and right-click behavior on webpages that restrict these actions.

Click the extension icon in the toolbar or use the keyboard shortcut to enable copying and right click on the current tab.

You can also add trusted websites to the Automatic Sites list. The extension will then enable copy and right click automatically whenever you visit those sites.

KEY FEATURES

• Enable copying and text selection on restricted webpages
• Enable right-click context menus
• Enable copy, cut, paste, text selection, and drag actions
• One-click activation from the toolbar
• Keyboard shortcut for quick activation
• Automatic activation on user-selected sites
• Works with accessible iframes where browser permissions allow
• Shows an ON badge after manual activation
• No popup menus
• No analytics or tracking
• No remote code or network requests

KEYBOARD SHORTCUTS

Windows: Alt+C
Linux: Alt+C
ChromeOS: Alt+C
macOS: Command+Shift+Y

The keyboard shortcut performs the same action as clicking the extension icon.

CHANGE THE KEYBOARD SHORTCUT

Chromium-based browsers:

1. Open chrome://extensions/shortcuts
2. Find Enable Copy and Right Click.
3. Enter your preferred keyboard shortcut.

Firefox:

1. Open about:addons
2. Select Extensions.
3. Click the gear icon.
4. Select Manage Extension Shortcuts.
5. Find Enable Copy and Right Click.
6. Enter your preferred keyboard shortcut.

AUTOMATIC SITES

Open the extension options page and add a domain such as:

example.com

The extension will ask for permission only for the website you add. Once permission is granted, copy, text selection, and right click will be enabled automatically on that site.

You can remove an automatic site at any time from the options page.

OPEN THE OPTIONS PAGE

Chromium-based browsers:

1. Right-click the extension icon in the browser toolbar.
2. Select Options.

Firefox:

1. Open about:addons
2. Select Extensions.
3. Find Enable Copy and Right Click.
4. Click the three-dot menu next to the extension.
5. Select Preferences.

PRIVACY

• No analytics or tracking
• No data collection
• No browsing history collection
• No network requests
• No remote code
• No external JavaScript
• Automatic-site preferences are stored locally in your browser
• Site permissions are requested only when you explicitly add a site

All copy and right-click restoration happens locally in your browser.

PERFORMANCE

The extension is lightweight and event-driven.

It performs no continuous background work while idle. Manual activation runs only when you click the toolbar icon or use the keyboard shortcut. Automatic activation runs only on websites you have explicitly added.

There is no polling, background network activity, analytics SDK, remote configuration, or persistent page-monitoring loop.
